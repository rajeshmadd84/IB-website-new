# public/images

Drop image assets here — served from the site root (e.g. `public/images/logo.svg`
→ `/images/logo.svg`). The site uses no images (visuals are CSS + animated SVG), so
this can stay empty. Worth adding if you want them:

- Favicon  → place at `app/favicon.ico` (Next auto-detects it; not here)
- OG image → place at `app/opengraph-image.png` (1200×630)
- Logo     → `public/images/logo.svg` (optional; design uses a text wordmark)

Use the `next/image` component to render images.
